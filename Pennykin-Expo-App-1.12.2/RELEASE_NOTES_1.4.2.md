# Pennykin 1.4.2 — Detailed Pet Actions

This update replaces prop-only care feedback with clearer character actions.

- **Rest:** each pet now changes into a purpose-built lying-down pose with closed eyes and slow breathing.
- **Feed:** the snack travels toward the pet and the character visibly opens its mouth before chewing.
- **Play:** the pet chases the toy with stronger side-to-side movement and two visible jumps per cycle.
- **Clean:** a full bath scene now includes an illustrated bathtub, moving scrub sponge, rising foam bubbles, and animated rinse streams.
- **Save celebration:** saving a new expense immediately opens the Pet tab, where the pet jumps while multicolored confetti falls through the room.
- **Idle behavior:** pets retain gentle breathing and occasional blinking, but no longer sway when the user is not interacting.
- **Reliability:** all new action art is preloaded with the core room artwork and keeps the existing loading fallback.
