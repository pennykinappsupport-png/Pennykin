# Pennykin 1.6.0 — Money Insights

This release moves Pennykin beyond recording totals by turning weekly data into four practical financial-learning tools.

## What changed

- Added Opportunity Cost feedback for every new Want. After saving, the Pet page compares the purchase with current Safe to Spend days and, when available, the remaining savings-goal gap.
- Added a weekly Opportunity Cost summary for total Wants inside Insights.
- Reframed the existing forecast as Spending Pace, showing actual daily pace, a budget-based daily baseline, a pace ratio, and a clearly labeled estimate.
- Added Budget Flexibility: the share of the weekly budget still available after recorded Needs and reserved future expenses.
- Added Forward-looking Reset messaging. Past spending remains recorded, while today’s flexible amount is recalculated from the money and days that remain.
- Added neutral pet responses for a forecast above plan, one category above plan while the total remains on track, and a low Safe to Spend amount.
- Preserved the core rule that spending amount never changes pet rewards.
- All calculations continue to run locally from the on-device SQLite data.
