# Pennykin 1.6.1 — Explainable Money Insights

## What changed

- Added a consistent circular information control to Opportunity Cost, Spending Pace, Budget Flexibility, and Forward-looking Reset.
- Each control opens a scrollable bottom sheet with five sections: what the metric means, how it is calculated, the user's current numbers, limitations, and why Pennykin shows it.
- Formula examples now substitute live on-device values from the current week instead of relying on fixed examples.
- Added safe handling for incomplete forecasts, zero-dollar Safe to Spend values, and missing savings goals.
- Added the same Opportunity Cost explanation to the post-check-in card on the Pet screen.
- Added accessibility labels, 44-point touch targets, tap-outside dismissal, a close control, and a final “Got it” action.
- Updated the public version to 1.6.1, iOS build number to 21, and Android version code to 21.

## Product boundary

The explanations are educational context, not financial advice. They remain neutral, never classify a purchase as bad, and never alter or hide the user's transaction history.
